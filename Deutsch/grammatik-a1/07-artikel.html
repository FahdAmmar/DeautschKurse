أدوات التعريف والتنكير Artikel

في العربية «ال» واحدة لكل شيء، أما الألمانية فلكل اسم أداة: der أو die أو das. نتعلم الأجناس الثلاثة وأنهاءات الأسماء التي تكشفها، والجمع، والفرق بين الأداة المعرّفة والنكرة، ومتى لا نستخدم أداة، والنفي بـ kein، ونظرة أولى على المفعول المباشر.

كل اسم ألماني له جنس: مذكر أو مؤنث أو محايد

في العربية أداة واحدة هي «ال». أما في الألمانية فلكل اسم أداة خاصة: der أو die أو das. الجنس النحوي لا علاقة له بالمعنى: der Tisch (مذكر) وdie Lampe (مؤنث) وdas Auto (محايد). لذلك نحفظ كل اسم مع أداته دائمًا.

الطاولة كبيرة.

ثلاث قواعد للبداية

١) احفظ الاسم مع أداته: der Tisch وليس Tisch. ٢) الجمع دائمًا die. ٣) تعلّم أنهاءات الأسماء، فهي تكشف الجنس: -ung ⇐ die، -chen ⇐ das.

لا ترجم من العربية. احفظ الاسم مع أداته، واستعن بالأنهاءات لتخمين الجنس.

Plural · الجمع02 / Plural

الجمع: die دائمًا

تعلّم الجمع مع كل اسم جديد: das Kind, die Kinder.

👥

في الجمع الأداة دائمًا die

لا فرق بين الأجناس في الجمع: die Tische · die Lampen · die Autos. لكن يتغيّر شكل الاسم نفسه، ولا توجد قاعدة واحدة، فنحفظ الجمع مع المفرد.

نمط الجمعالمفردالجمع
-eder Tisch · der Hunddie Tische · die Hunde
-e + umlautder Stuhl · die Stadtdie Stühle · die Städte
-er (+ umlaut)das Kind · das Buch · das Hausdie Kinder · die Bücher · die Häuser
-(e)ndie Lampe · die Frau · die Zeitungdie Lampen · die Frauen · die Zeitungen
-sdas Auto · das Handy · das Hoteldie Autos · die Handys · die Hotels
بلا تغيير (أو umlaut)der Lehrer · das Zimmer · der Apfeldie Lehrer · die Zimmer · die Äpfel
🎯

نصيحة

الأسماء المؤنثة غالبًا جمعها -n / -en: die Frau → die Frauen. والأسماء الأجنبية القصيرة جمعها -s: das Auto → die Autos. والمحايد القصير غالبًا -er: das Kind → die Kinder.

✓Die Kinder spielen.

الجمع دائمًا die، والفعل جمع.

تمرين: رتّب الجملة

die + اسم جمع + فعل جمع.

Gebrauch · الاستخدام03 / Gebrauch

معرّف أم نكرة أم بلا أداة؟

القاعدة: جديد ⇐ ein، معروف ⇐ der، مهنة أو لغة أو مادة ⇐ بلا أداة.

1️⃣

ein / eine / ein: «واحد» أو اسم جديد

ein للمذكر والمحايد، eine للمؤنث. وليس لها جمع. نستخدمها عندما نذكر شيئًا لأول مرة أو لا نحدّده: Das ist ein Hund.

ein

Das ist ein Hund.

هذا كلب.

eine

Das ist eine Katze.

هذه قطة.

ein

Das ist ein Auto.

هذه سيارة.

eine

Ich habe eine Schwester.

لدي أخت.

🔁

نذكر الشيء أولًا بـ ein ثم نعرّفه بـ der

Ich habe einen Hund. Der Hund heißt Max. الأول جديد ⇐ ein، والثاني معروف ⇐ der. وأيضًا مع الشيء الوحيد: die Sonne, der Mond.

الحالةالأداةمثال
شيء جديدein / eineIch habe eine Katze.
شيء معروفder / die / dasDie Katze ist klein.
شيء وحيدder / die / dasDie Sonne scheint.
🚫

بلا أداة: المهن والجنسيات واللغات والمواد

Ich bin Lehrer. · Er ist Syrer. · Ich spreche Deutsch. · Ich trinke Wasser. · Ich esse Brot. · Ich habe Kinder. (جمع نكرة) · Ich wohne in Deutschland.

الحالةمثالالمعنى
مهنةIch bin Lehrer. أنا معلّم
جنسيةSie ist Ägypterin. هي مصرية
لغةWir sprechen Arabisch. نتكلم العربية
مادة غير معدودةIch trinke Tee. أشرب الشاي
جمع نكرةEr hat Freunde. لديه أصدقاء
اسم علمAnna wohnt in Berlin. تسكن آنا في برلين
🙅

النفي بـ kein

kein يعني «لا ... أي»، ويأخذ نهايات ein: kein Auto, keine Katze, keine Kinder. ونستخدم nicht مع الأفعال والصفات: Ich bin nicht müde.

kein

Ich habe kein Auto.

ليس لدي سيارة.

keine

Das ist keine Katze.

هذه ليست قطة.

keine (Plural)

Er hat keine Kinder.

ليس لديه أطفال.

nicht

Ich bin nicht müde.

لست متعبًا.

⚠️ خطأ شائع: أداة مع المهنة

✗Ich bin ein Lehrer.
✓Ich bin Lehrer.

المهنة بلا أداة بعد sein.

⚠️ خطأ شائع: أداة مع اللغة

✗Ich spreche das Deutsch.
✓Ich spreche Deutsch.

اللغات بلا أداة بعد sprechen.

⚠️ خطأ شائع: nicht مع اسم نكرة

✗Ich habe nicht Auto.
✓Ich habe kein Auto.

نفي الاسم النكرة ⇐ kein.

🧩

تمرين: رتّب الجملة

ich + habe + eine + اسم.

Akkusativ · نظرة أولى04 / Akkusativ

مع المفعول: der ⇐ den، ein ⇐ einen

هذه نظرة أولى فقط على المفعول المباشر، وسنتوسع فيه لاحقًا.

🎯

المفعول المباشر: المذكر فقط يتغيّر

بعد أفعال مثل haben, sehen, kaufen, brauchen, möchten, suchen يأتي المفعول المباشر في Akkusativ: der → den وein → einen وkein → keinen. أما die وdas وeine وein فلا تتغيّر.

Nominativ (فاعل)Akkusativ (مفعول)
مذكرder / ein / keinden / einen / keinen
مؤنثdie / eine / keinedie / eine / keine
محايدdas / ein / keindas / ein / kein
جمعdie / — / keinedie / — / keine
einen

Ich habe einen Hund.

لدي كلب. (مذكر ⇐ einen)

den

Ich sehe den Mann.

أرى الرجل.

einen

Ich möchte einen Kaffee.

أريد قهوة.

die

Ich suche die Katze.

أبحث عن القطة. (مؤنث بلا تغيّر)

فعلمثالالمعنى
habenIch habe einen Bruder. لدي أخ
kaufenIch kaufe den Tisch. أشتري الطاولة
brauchenIch brauche einen Stuhl. أحتاج كرسيًا
möchtenIch möchte einen Tee. أريد شايًا
sehenIch sehe den Hund. أرى الكلب

⚠️ خطأ شائع: ein مكان einen

✗Ich habe ein Hund.
✓Ich habe einen Hund.

مفعول مذكر ⇐ einen.

⚠️ خطأ شائع: der مكان den

✗Ich sehe der Mann.
✓Ich sehe den Mann.

مفعول مذكر ⇐ den.

🧩

تمرين: رتّب الجملة

ich + möchte + einen + اسم مذكر.
